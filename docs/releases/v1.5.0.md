# v1.5.0 — Better keyboard controls

- **Home / End** move to the first or last cell in the current row. Arrow keys stop at board edges, consistently across Classic, Quick, Introduction, variants and technique practice.
- Press **?** for keyboard help tailored to the current board and mode. Escape closes it and returns focus; the saved Show / Hide shortcuts preference stays intact.
- Holding an action key performs the action once: hints, Check, notes and pause no longer repeat accidentally. Release and press again to act immediately, with no cooldown. Arrow navigation and modified undo / redo shortcuts still repeat normally.
- Gameplay shortcuts apply while a grid cell has focus, leaving buttons and text fields to use their normal keyboard behavior. Small boards and variants now match Classic for Enter to check, Escape to cancel a hint or deselect, and both redo shortcuts.
- **P or Space** pauses and resumes from the grid. Small-board keyboard focus now follows the selected cell and hint target reliably.

Keyboard documentation and browser coverage have been expanded, including iPhone WebKit.
