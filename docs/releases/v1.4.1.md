# v1.4.1 — Clearer navigation and sharing

- Use **New game** to choose a puzzle. The redundant Play button is hidden during play; Solver shows **Back to game**, which resumes your saved Classic game or opens the chooser when there is no saved game.
- Starting or resuming a Classic game now clears stale pause overlays and restores the Pause control.
- Stabilize initial board sizing in iPhone WebKit when fonts finish loading.
- **Share puzzle** is directly available while paused and after completion, including Quick, Introduction, Diagonal and Hyper games. Sharing keeps local progress and offers the link for manual copying when clipboard access is unavailable. Inside Puzzle tools, the link stays in the text box so you can continue exporting or printing.
- **Export & print** consistently names the combined text, image and worksheet panel. **Print / Save PDF** remains the printing action.

Puzzle identities, daily mappings, saved-game formats and leaderboard behavior are unchanged.
