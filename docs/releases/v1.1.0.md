# v1.1.0 — Better hints and puzzle tools

- Import a unique puzzle directly into Play, with an on-device technique assessment.
- Preview hints for free before choosing Reveal. Expanded deductions include
  uniqueness rectangles, BUG+1 and checked chains, with optional candidate maps
  and detailed explanations.
- Generate puzzles with reproducible seeds, clue targets and symmetry options.
  Export PNG images for messaging or print multi-puzzle worksheets with answers.
- Undo automatic-note changes and restore peer notes. Review, share and export
  completed puzzles, then undo without recording the same win twice.
- Improved keyboard controls, backups, small-screen layout, offline startup and
  optional self-hosted leaderboard persistence.
- Repeatable maintenance assessment for existing, newly added and imported
  puzzles, with opening measurements, proof complexity and alternative paths.

The v4 maintenance profile explains all 5,500 bank puzzles. It explains 40 of an
80-puzzle sample from two harder external collections; unfinished assessments
remain unranked. These are this engine's observed reasoning paths, not exact
Sudoku Explainer grades or proof that no simpler solution exists.

Existing 9×9 puzzle positions, daily puzzles and score references remain unchanged.
Reclassification and reordering require a separate review of the assessment and
migration policy. Earlier reports and rating executables remain available.

Validation includes full-bank uniqueness checks, unit tests, both build targets,
Chromium/mobile/WebKit behavior, theme contrast and container checks from the
preceding audit. The optional leaderboard continues to use client-reported results.
