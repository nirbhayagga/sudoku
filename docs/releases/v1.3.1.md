# v1.3.1 — Layout, menus and digit styling

- Preserve notch and home-indicator spacing on narrow iPhones.
- Keep board sizing stable with Reduce Motion and viewport changes.
- Show a steady loading view while shared puzzles load, avoiding a flash of setup menus.
- Fix the board-size selector's painted colors in dark themes on WebKit.
- Put saved-game Resume above the board and include the puzzle level.
- Keep Close visible in long dialogs, contain scrolling, and improve keyboard focus handling.
- Make Practice directly accessible beside Play/Solver.
- Fold small-board/variant setup during play, improve number-pad labels, and separate text, print and backup tools.
- Use a more compact desktop/tablet layout with controls beside the board.
- Restore the original entry weight in Light/Dark, use consistent digit fonts across boards, and prevent buttons moving under touch input.

All ten themes remain available. Puzzle identities, bank order and saved-game formats are unchanged.

Validation: lint, both build targets, 932 unit/API tests with full-bank verification,
and 353 browser checks passed (30 expected platform skips). The final width
correction also passed targeted desktop, touch and WebKit layout checks. All ten
themes passed computed contrast; native selector painting has separate pixel checks.

iPhone layout coverage uses Linux WebKit with modeled safe-area insets. A physical
installed-iPhone PWA was not exercised in this validation.
